# RealAgents.ai

## Project Overview

This project analyzes house sales data for a real estate company, RealAgents.

The analysis focuses on cleaning the house sales data, exploring the relationship between the number of bedrooms and sale prices, and building machine learning models to predict house prices.

## Dataset

The project uses three CSV files:

- `house_sales.csv` — Original house sales data
- `train.csv` — Training data for machine learning
- `validation.csv` — Data used to generate house price predictions
